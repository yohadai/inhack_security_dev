## 기본 과제 (전원 필수)

본인 레포에 `docs/week01.md` 를 만들어 아래를 정리하고 PR을 올리세요.

### 1) 토큰 실습 정리
- 내 토큰으로 `https://api.github.com/user` 를 호출했을 때 **무엇이 보였는지** (실제 값은 가리고, 항목만: 예 "이메일, 이름, private 레포 목록")

내가 가지고 있는 모든 레포의 정보들이 나왔다. (id, node_id, name, permissions 등...)
 
- 토큰을 **Revoke** 한 뒤 같은 호출이 어떻게 달라졌는지

{
  "message": "Bad credentials",
  "documentation_url": "https://docs.github.com/rest",
  "status": "401"
}
- **Fine-grained token**(레포 1개 + 만료일)으로 새로 발급한 뒤, 보이는 범위가 어떻게 줄었는지

설정한 1개의 레포에 대한 정보만 나왔다. 권한도 아예 주지 않았더니 이전 토큰에 비해 레포당 출력하는 정보의 가지수도 줄었다.
- 한 줄 소감: "권한을 좁게 준다"가 왜 중요한지

개발자가 실수로 토큰을 유출하는 것을 24시간 감시하고 있는 해커에게 토큰이 유출되었을 때 해커가 알아낼 수 있는 정보가 줄어든다. 

### 2) 키가 새는 실수 5가지 정리
수업에서 본 5가지를 각각 **"무엇을 / 왜 위험한지 / 어떻게 하면 안 새는지"** 한두 줄로:
1. 코드에 하드코딩

코드에 api 키나 깃헙 토큰 등의 내부 정보를 하드코딩하고 이를 오픈된 레포에 올리면 해커가 탈취해갈 수 있다. 
2. `.env` 만 만들고 `.gitignore` 안 함

.gitignore에 .env를 넣어주지 않으면 .env파일 또한 커밋되어 올라간다.


3. `.gitignore` 를 나중에 추가 (이미 추적 중인 파일)

이미 추적 중인 파일은 .gitignore에 뒤늦게 올려도 계속 추적된다. 미리 .gitignore에 올려놓고 커밋해야한다.

4. 변형 파일 (`.env.local` 등)

.env 만 .gitignore에 넣어놓으면 .env.local같은 변형 파일들은 추적 대상에서 제외되지 않는다. .env.*를 .gitignore에 넣어 변형 파일도 추적 대상에서 제외시킨다.

5. PR·댓글에 붙여넣기 (수정해도 편집 기록에 남음)

중요 정보를 공개된 곳에 붙여넣으면 외부인이 볼 수 있다. 중요 정보는 외부에 올리면 안 된다.

## 추가 과제 (하고 싶은 사람만)

여기까지 하면 2주차(도구로 자동 차단)로 자연스럽게 이어집니다.

### STEP 1 — "안 새게 막는 규칙" 만들기
본인 레포 루트에 `.gitignore` 를 만들어 `.env` **와 그 변형까지** 막아 보세요.

```gitignore
.env
.env.*
!.env.example
*.pem
*.key
```

`docs/week01.md` 에 "왜 `.env.*` 까지 넣었는지" 한 줄 적기 (수업 실수 #4와 연결).

* 로 .env. 뒤에 어떤 변형된 이름이 와도 git이 추적하지 않도록 한다.

### STEP 2 — 실제로 막히는지 검증
직접 확인하고 결과(명령어 + 결과 한 줄)를 적으세요.

```bash
# 1) 새 .env 는 무시되는가?
echo "API_KEY=ghp_가짜키" > .env
git status            # → .env 가 안 보이면 성공

# 2) 변형 파일도 무시되는가?
echo "API_KEY=ghp_가짜키" > .env.local
git status            # → .env.local 도 안 보이면 성공

# 3) '이미 추적 중이던' 파일은? (수업 실수 #3)
#    만약 예전에 실수로 .env 를 커밋했다면, .gitignore 만으로는 안 빠집니다.
git rm --cached .env  # 추적에서 제외 (파일은 로컬에 남음)
git status            # → 이제 삭제로 잡히고, 이후로는 무시됨
```

* .env 무시되는 것 확인, 변형 파일 무시되는것 확인. !.env.example에서 앞에 붙은!는 .gitignore에서 제외함을 의미한다. .env.example은 git에서 추적되는 것 확인.

``` bash
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        .env.example
```

> 정리: `.gitignore` 는 **아직 추적 안 하는 파일**만 막습니다.
> 이미 커밋된 시크릿은 `git rm --cached` 로 추적을 빼야 하고,
> **이미 새어나간 값은 반드시 폐기·교체**해야 합니다. (다음 주에 이걸 자동으로 잡는 도구를 씁니다.)
